# Yuki 屏幕日报（安卓小应用）

每晚 22:00 自动统计当天屏幕使用（总时长 + 用得最多的 5 个应用），以飞书机器人身份发进「muse伴学」群。Yuki 每天早上读群里这条日报，记进手机时长账，晨间卡会显示"昨日屏幕 X 小时"。

只发汇总数字和应用名，不发任何使用内容。App Secret 只存在手机本地。

> **适用系统：鸿蒙 4.x**（华为 Mate 60，鸿蒙 4 兼容安卓应用，这个 APK 可以装）。如果是**纯血鸿蒙 NEXT（5.x）**，安卓应用装不了，这个包用不上——那种情况告诉 Yuki，走备选方案。

## 你要做的（约 10 分钟）

### 1. 拿 APK（已编译好，不用装 Android Studio）
现成 APK 已由 Yuki 在服务器上编译并签名验过：`dist/Yuki屏幕日报-debug.apk`（697 KB，包名 cn.yuki.usagereport，minSdk 26 / targetSdk 35，调试签名、自用侧载没问题）。直接跳到第 2 步。
（兜底：万一这个 APK 装不上，再走 Android Studio 打开本文件夹 Build → Build APK(s) 自己编一份。注意源码里 UsageReader 的一处常量笔误已由 Yuki 修复：MATCH_OBJECT_ALL 改为 0，否则编译不过。）

### 2. 装到手机（文件传输 + 手动安装）
1. 把 `dist/Yuki屏幕日报-debug.apk` 通过 QQ / 微信 / 飞书发给自己（文件传输助手），或用华为云空间、U盘中转，下载到 Mate 60。
2. 在手机上点开这个 APK 文件安装，允许"外部来源应用安装"。
3. 若被**纯净模式**拦截：设置 → 系统和更新 → 纯净模式 → 关闭（或在拦截弹窗里按提示放行）。
4. Mate 60 鸿蒙 4.x 可以直接装安卓 APK。

### 3. 配置 + 授权（在应用界面里）
1. App ID 和群 chat_id 已预填，不用改。
2. App Secret：去飞书开放平台 → 你的应用（Yuki）→ 凭证与基础信息，复制 App Secret 粘贴进来，点「保存配置」。
3. 点「① 打开『使用情况访问』授权」，在系统列表里找到「Yuki屏幕日报」，打开开关。若列表里没有它：设置 → 应用和服务 → 应用管理 → 右上角菜单 → 特殊访问权限 → 使用情况访问数据 → 找到本应用打开。
4. 点「② 电池优化设为无限制」并确认（鸿蒙上这个按钮可能跳不到准确页面，按下一条手动设即可）。
5. **华为保活（必做）**：设置 → 电池 → 应用启动管理 → 找到「Yuki屏幕日报」→ 关闭「自动管理」→ 弹出框里三个开关全开（允许自启动 / 关联启动 / 后台活动）；再在最近任务里长按应用卡片锁定。

### 4. 测试
点「立即上报一次（测试）」——飞书群里出现一条"📱 屏幕使用日报"就通了。当天 22:00 的自动上报会因为"今天已上报"自动跳过，从明晚起每晚自动发。

## 出问题时
- 状态栏显示"未授予使用情况访问权限"：重做第 3 步第 3 项；鸿蒙上也可以在「设置 → 隐私 → 权限管理」附近找「使用情况访问」。
- 群里没消息且提示发送失败：多半是 Secret 粘错了，或应用的发消息权限被关；把状态栏的报错发给 Yuki 看。
- 22:00 没自动发：基本是保活没做全（应用启动管理三开关），重做第 5 项；也可以每天随手打开一次应用，它会自检并重排闹钟。
- **装不上（解析包失败/不兼容）**：多半是手机已经升到纯血鸿蒙 NEXT，安卓应用无法安装。把「设置 → 关于手机」的系统版本发给 Yuki，换备选方案。
