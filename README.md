# Yuki 屏幕日报（安卓小应用）

每晚 22:00 自动统计当天屏幕使用（总时长 + 用得最多的 5 个应用），以你自己的飞书机器人身份发进你指定的飞书群。

只发汇总数字和应用名，不发任何使用内容。三项飞书配置（App ID、App Secret、群 chat_id）都在应用界面里填写，只存在手机本地，源码不带任何人的凭据。

## 自己部署（约 15 分钟）

### 1. 准备一个飞书自建应用

1. 到飞书开放平台（open.feishu.cn）创建一个**企业自建应用**，在「凭证与基础信息」里拿到 **App ID** 和 **App Secret**。
2. 给应用开通发送消息权限（`im:message`），并把应用机器人拉进一个群（可以只有你自己的群）。
3. 拿群的 **chat_id**（`oc_` 开头）：在开放平台的 API 调试台里，以应用身份调用「获取机器人所在群列表」（`GET /open-apis/im/v1/chats`），返回里目标群的那串就是。

### 2. 编译安装

用 Android Studio 打开本项目，Build → Build APK(s)，把 APK 装到手机上（允许「外部来源应用安装」）。需要 Android 8.0（API 26）以上；纯血鸿蒙 NEXT（5.x）装不了安卓应用。

### 3. 配置 + 授权（在应用界面里）

1. 把第 1 步的 App ID、App Secret、群 chat_id 三项填进去，点「保存配置」。
2. 点「① 打开『使用情况访问』授权」，在系统列表里找到「Yuki屏幕日报」打开开关。
3. 点「② 电池优化设为无限制」并确认。
4. **保活（重要，不然 22:00 的定时会被系统杀掉）**：在手机的电池 / 应用启动管理里，允许本应用自启动、关联启动和后台活动；再在最近任务里锁定本应用卡片。华为（鸿蒙 4）：设置 → 电池 → 应用启动管理 → 关闭「自动管理」→ 三个开关全开。

### 4. 测试

点「立即上报一次（测试）」——群里出现一条「📱 屏幕使用日报」就通了。当天 22:00 的自动上报会因为「今天已上报」自动跳过，从明晚起每晚自动发。

## 出问题时

- 状态显示「未授予使用情况访问权限」：重做第 3 步第 2 项；找不到开关时走 设置 → 应用管理 → 特殊访问权限 → 使用情况访问数据。
- 发送失败：多半是三项配置填错，或应用没开通发消息权限、机器人不在群里，对照第 1 步检查。
- 22:00 没自动发：基本是保活没做全；也可以每天随手打开一次应用，它会自检并重排闹钟。
